# Gerenciador de Gastos
Projeto desevolvido em Python para praticar lógica de programação e organização de código.

## Funcionalidades
- Cadastro de gastos
- Validação de valores
- Visualização dos gastos cadastrados
- Cálculo do total de gastos
- Busca de gastos por categoria 
- Menu interativo
